# ALUFORM Website

Static multi-page aluminum fabrication website.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `products.html` — Products
- `contact.html` — Contact

## Run or deploy

No build tool is required. Open `index.html` in a browser or upload this folder, preserving its relative paths, to a static web host.

## Before publishing

Replace the ALUFORM brand name and the `[Your Region]`, `[Your phone number]`, `[City, Region]`, and `hello@yourcompany.com` placeholders. Update the `mailto:` recipient in `site.js` to the real business email. The quote form opens an email draft; it does not submit to a server.
